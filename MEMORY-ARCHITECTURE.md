# Memory Architecture

**Philosophy:** Files are memory. Git is history. No external databases, no cloud dependencies.

Everything an agent knows lives in readable, editable, version-controlled files.

---

## The Stack

```
Layer           Location                              Updates          Purpose
────────────────────────────────────────────────────────────────────────────────
Identity        SOUL.md, IDENTITY.md, USER.md         Rare             Who I am, who you are
Long-term       MEMORY.md                             Weekly           Key facts, preferences, goals
Channel context memory/channel-{name}.md              On channel switch What happened in each Discord channel
Daily logs      memory/YYYY-MM-DD-*.md                On /new          Session summaries (auto via hook)
Open loops      memory/open-loops.md                  Per heartbeat    Blocked/pending items
Obsidian        ~/Projects/BrainObsidian/             During work      Projects, next actions, daily notes
Session logs    ~/.openclaw/agents/*/sessions/*.jsonl  Auto             Raw transcripts (OpenClaw managed)
Shared          Claw-HiveMind repo                    On commit        Cross-agent skills, state, context
```

---

## How Each Layer Works

### Identity (SOUL.md, IDENTITY.md, USER.md)
- Loaded automatically every session via workspace context injection
- Rarely changes — only when something fundamental shifts
- Agent can propose edits but should flag them to the human

### Long-term Memory (MEMORY.md)
- The agent's "personality file" — key facts, preferences, working relationships
- Updated ~weekly or when significant new context is learned
- Read in main session; channel sessions may skip unless relevant

### Channel Context (memory/channel-{name}.md)
- **Written:** When leaving a channel or going idle
- **Read:** On session start — current channel + most recently modified channel
- Max 30 lines — summary, not transcript
- Contains: what was discussed, decisions made, active threads, people present

### Daily Logs (memory/YYYY-MM-DD-*.md)
- Auto-generated by session-memory hook on `/new`
- Contains last 15 messages from the session
- Filename is LLM-generated slug (e.g. `2026-02-20-state-yaml-pattern.md`)
- Read-only archive — don't edit these

### Open Loops (memory/open-loops.md)
- Actively maintained list of pending/blocked items
- Checked every heartbeat (30 min)
- Items get status: ⏳ pending, 🔄 in-progress, ✅ done, 🚫 blocked

### Obsidian Brain (~/Projects/BrainObsidian/)
- The human's knowledge base — agents read and write here
- `Brain/Next Action List.md` — GTD task list
- `Brain/Agent/Sessions/` — agent session logs
- `Brain/Agent/Projects/` — project-specific notes
- Daily notes at root (`YYYY-MM-DD.md`)
- Git-synced: `cd ~/Projects/BrainObsidian && git add . && git commit -m "..." && git push`

### Session Logs (~/.openclaw/agents/*/sessions/)
- Raw JSONL transcripts — every message, tool call, response
- Managed by OpenClaw, not manually edited
- Searchable via session-logs skill
- Use for debugging, auditing, or recovering lost context

### Shared Repo (Claw-HiveMind)
- `github.com/Blueshadow0107/Claw-HiveMind`
- Skills, STATE.yaml patterns, channel context, cron definitions
- All agents can pull from here for shared context
- Push after creating anything other agents should know about

## Rules

1. **Files are the source of truth.** If it's not in a file, it doesn't exist.
2. **Git everything.** Workspace and Obsidian are git-tracked. Commit after meaningful changes.
3. **No external memory services.** No vector DBs, no cloud memory APIs. Files + grep + session-logs skill.
4. **Channel context is mandatory.** Always read on session start, always write on session end.
5. **Don't duplicate.** One fact lives in one place. MEMORY.md for personal context, Obsidian for project context, channel files for session context.
6. **Keep it small.** Channel summaries < 30 lines. MEMORY.md < 200 lines. If it's growing, archive or restructure.

---

## Search Strategy

When looking for information:

1. **Recent?** → Read channel context file
2. **About the human?** → USER.md, MEMORY.md
3. **About a project?** → Obsidian `Brain/Agent/Projects/`
4. **About a past session?** → `memory/YYYY-MM-DD-*.md` or session-logs skill
5. **About a task?** → `memory/open-loops.md` or Obsidian `Brain/Next Action List.md`
6. **Cross-agent?** → Claw-HiveMind repo

No magic retrieval — know where things live and go read them.
